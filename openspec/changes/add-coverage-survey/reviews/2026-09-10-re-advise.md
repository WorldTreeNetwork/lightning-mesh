## Notes (not blocking)

- **Where "nearby radio strength" comes from.** design call 1 says the
  phone "sees … radio strength of nearby nodes." A phone browser on
  hello.mesh cannot scan Wi-Fi. The signal that exists on the same
  gateway is `GET /api/radio` on the associated node: its `stations` are
  mesh peers with RSSI, a proxy for which nodes are near the AP the phone
  is on. When `add-compass-node-mark` builds the list, rank by that (or
  by the client-AP station dump), and do not owe a phone-side scan. One
  sentence in the ADR would close it: "the nearby ranking is
  node-observed RSSI from the associated node, not a phone scan."
- **Geolocation needs HTTPS.** `navigator.geolocation` is refused on
  insecure origins by every current mobile browser, and hello serves
  plain HTTP on `10.42.<x>.1:80`. Typed (or pasted from a maps app) is
  the v1 path in practice; the geolocation button is a bonus that will
  not fire until hello has TLS. Say "typed is guaranteed; geolocation is
  opportunistic" so the sibling does not ship a button that never works.
- **Who may stamp.** The client SSID is open by default
  (`ARCHITECTURE.md:20`). `POST /api/identity` verifies a signature but
  any fresh key passes; name-claim then binds authority to that key
  (first-writer-wins per name). A coordinate stamp has no per-key
  ownership: LWW on `stamped_at` means the latest verified key wins for
  any `node_id`. The delta records the stamper, which is enough to filter
  after the fact, but the ADR should state the v1 trust model in one line
  (any verified key may stamp; stamper is recorded; restricting to the
  identity book or operator keys is `add-node-coordinates`' call). Not
  blocking because the CRDT authority and stamper provenance are already
  pinned; only the gate is undecided.
- **Node point vs coverage.** Call 5 derives region completeness from
  "geolocated RSSI samples plus node radio footprints." v1 stores only
  node points; the RSSI samples are the sweep (`add-coverage-sweep`).
  Fine, but the first `/mesh` paint will be node points plus mesh-link
  RSSI, a proxy. Worth one word in call 5 so the viewer does not claim
  "covered" from a point.
- `tasks.md` "Advise accept" box is ticked by this pass (allowed path).
  ARCHITECTURE.md amendment remains the act.
